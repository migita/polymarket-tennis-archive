Market selection

Tennis-tagged match-winner markets with two named players. Doubles, tournament winners, handicaps, and totals are excluded. Separate listings remain separate market IDs. Match dates use the API’s scheduled start and may differ from actual play.

Live quotes and refresh

Refresh discovers open singles markets above $5,000 through Polymarket Gamma, then reads both players’ order books. Live decimal odds are the reciprocal of each token’s lowest available ask, before fees. An empty ask book is shown as unavailable. Failed refreshes mark retained quotes as stale. Refresh only runs while the page is open; the interval is saved in this browser. Refresh also checks for a newly published archive.

Historical precision

Recent histories request 15-minute buckets, older data 30-minute or 3-hour buckets, with coarser fallback. Timestamps mark bucket starts. Pre-match includes only buckets ending by the scheduled start; buckets crossing it are excluded. Actual gaps may be longer than the stated resolution. Zero-resolution terminal points are omitted because they can represent either exact ticks or synthetic settlement payouts. Missing prices are not invented.

Sources and downloads

The historical database is a fixed snapshot. Live browser quotes are separate and are not written back to it. Collection manifest · Gamma documentation · Price history documentation. The database has markets, prices and metadata tables. All times are UTC.
