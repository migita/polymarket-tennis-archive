What’s in the archive.

A single collection of publicly available Polymarket data.

↓ Download the SQLite database
Which matches are included?

Tennis-tagged match-winner markets with two named players and recorded market volume strictly above $5,000. Match dates use Polymarket’s scheduled start time. Doubles, tournament winners, handicaps, totals, and completed-match bets are excluded. The archive covers discoverable markets, not every tennis match played. Separate Polymarket listings remain separate rows.

How precise is the price history?

Recent histories request 15-minute prices. Older histories request 30-minute or 3-hour data, with coarser fallback where needed. Each observation retains the resolution and timestamp returned by Polymarket; actual gaps may be longer. No missing observations are invented. Zero-resolution terminal points are omitted because they can represent either exact ticks or synthetic settlement payouts. A market can be present even when price history is unavailable.

What do the odds and volume mean?

Decimal odds are 1 ÷ token price, before fees. For example, a $0.40 token corresponds to 2.50 decimal odds. Historical chart prices are not guaranteed executable buy quotes. “Pre-match” includes only price buckets ending by the API’s scheduled start, which can differ from actual play. Chart timestamps mark bucket starts, not exact observation times. The total volume filter cannot establish whether $5,000 was reached before the match.

Does the site keep collecting?

No. This is a one-off snapshot, served entirely from GitHub Pages. Reloading the site does not update market data. The repository includes a resumable import script and the database for independent analysis.

Sources and data format

Market metadata comes from Polymarket Gamma. Prices come from the Data API price-history endpoint. The collection manifest records coverage, exclusions, and errors. The ZIP contains a SQLite database with markets, prices, and metadata tables. Timestamps are Unix seconds in UTC.
